Как установить

Четыре шага — и система готова

Скачай ISO

Нажми «Скачать ISO» выше. Файл весит ~1.2 ГБ. Загрузка 5–15 минут.

Запиши на флешку

Используй Rufus. Флешка минимум 8 ГБ. Режим MBR (старый BIOS) или GPT (UEFI).

Загрузись с флешки

Перезагрузи ПК. F12/F2/Del → Boot Menu → USB. Secure Boot выключи.

Установи

Выбери «Install TYOMIKOS 1.0». Calamares проведёт по всем настройкам.

Частые вопросы

Ответы на то, что спрашивают чаще всего

Сотрётся ли Windows при установке?
Если выберешь «Стереть диск» — да, Windows удалится. Если выберешь «Рядом с Windows» — обе системы будут работать. При загрузке появится меню выбора.
Нужна ли флешка?
Да, для установки нужна флешка минимум 8 ГБ. Или используй приложение «Установщик для ISO» — оно поставит систему без флешки.
Пойдёт ли на старый компьютер?
Да, если процессор 64-битный (Intel Core 2 Duo и новее) и минимум 2 ГБ RAM. ТЁМИКOS с Xfce летает на старых ПК.
Какие драйверы Wi-Fi поддерживаются?
Intel, Realtek, Atheros, Broadcom. Если Wi-Fi не заработал, установи пакет firmware-b43-installer из магазина.
Можно ли запустить без установки?
Да, выбери в меню «Start TYOMIKOS (Live)». Система работает с флешки, но изменения не сохраняются. Для сохранения — выбери «Start with persistence».
Как обновлять систему?
В терминале: sudo apt update && sudo apt upgrade. Или через магазин приложений — там есть кнопка обновления.
